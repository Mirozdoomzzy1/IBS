# Enterprise Design Studio v12 - Mobile First

This is the v12 package rebuilt with a mobile-first responsive layer.

Key changes:
- Full slide-out navigation with every major page visible.
- Touch-friendly controls.
- Smooth drawer animation and overlay.
- No body-wide horizontal overflow.
- Responsive Screen Designer, ERD, Timeline, forms, dialogs and cards.
- Desktop layout remains available above 900px.
- iOS safe-area support.
- Drawer closes after navigation, overlay tap, Escape, or desktop resize.
