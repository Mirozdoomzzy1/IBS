# Screen Designer UX Upgrade
- Full component library stays visible on mobile in a dedicated scrollable panel.
- Tapping a component adds it without hiding the component library.
- Regions are containers; select a region before adding a component to place it inside automatically.
- Components can be assigned to a region from Properties > Place inside region.
- Desktop drag/drop and mobile pointer drag support moving components into regions.
- Global Sign out button is available in the application top actions; login remains available on the login screen.
- No database migration required.
